# 鲨鱼桌宠 (Shark Pet) 设计文档

## 概述

一个基于 Electron 的 Q 版可爱风鲨鱼桌宠，具备养成互动功能。鲨鱼在桌面上自由活动，用户可进行喂食、玩耍、摸摸等互动，各项数值随时间变化。

---

## 技术选型

- **Electron**：桌面应用壳，透明无边框窗口
- **Canvas API**：鲨鱼分部件程序化绘制
- **CSS Animations**：弹性动画（弹跳、摇摆、变形）
- **JSON 文件存储**：本地数据持久化

### 核心模块接口

```js
// shark.js — 鲨鱼渲染器（接口稳定，实现可替换）
class SharkRenderer {
  constructor(canvas)
  draw(state, animProgress)     // 根据状态绘制鲨鱼
  setAnimation(type, duration)  // 触发一次性动画
  update(dt)                    // 帧更新
}

// behavior.js — 行为状态机（可扩展新状态）
class BehaviorEngine {
  constructor(stats)
  get currentState()            // idle | walk | sleep | eat | play
  update(dt, stats)             // 状态决策 & 自动切换
  trigger(action)               // 用户触发：feed | play | pet
}

// stats.js — 数值管理（属性可扩展）
class StatsModel {
  constructor()
  get hunger / mood / energy / coins
  addCustomStat(key, range, decayRate)
  update(dt)                    // 衰减计算
  modify(key, delta)
  serialize() / deserialize(data)
}
```

### 扩展点设计

为确保后续易于扩展，以下位置预留接口：

1. **新状态**：behavior.js 的状态机使用策略模式，`registerState(name, handler)` 即可新增
2. **新属性**：StatsModel 支持 `addCustomStat()` 动态添加数值维度
3. **新动画**：SharkRenderer 的 `setAnimation()` 接受任意动画名，内部注册表扩展
4. **任务模块**：main.js 预留 `taskExecutor` 模块位，IPC channel `task:*` 已规划
5. **皮肤系统**：SharkRenderer 构造函数接受 `skinConfig`，传入不同配色/饰品配置

## 鲨鱼外观 & 动画

### 部件结构（Canvas 分部件绘制）

鲨鱼由以下独立部件组成，每个部件可独立控制动画：

- 身体（椭圆主体 + 渐变填充，蓝灰配色）
- 背鳍（三角形，可摆动）
- 胸鳍（两侧，可划水）
- 尾鳍（分叉，游泳时摆动）
- 眼睛（圆形，可眨眼）
- 嘴巴（弧线，可张合）
- 牙齿（小三角，张嘴时可见）
- 鳃裂（身体侧面弧线）

## 行为状态机

### 状态定义

```
      ┌──────────┐
      │   sleep  │ ← 体力 < 20 触发；睡到体力 > 80 醒来
      └────┬─────┘
           │
      ┌────▼─────┐  hunger < 30   ┌──────────┐
      │   idle   │ ────────────→  │   eat    │
      └────┬─────┘               └────┬─────┘
           │ 随机(30s CD)              │ 动画结束
      ┌────▼─────┐               ┌────▼─────┐
      │   walk   │               │   idle   │
      └────┬─────┘               └──────────┘
           │ 用户触发 play
      ┌────▼─────┐
      │   play   │ ──→ idle（动画结束）
      └──────────┘
```

### 状态切换规则

| 当前状态 | 可切换至 | 优先级 |
|---------|---------|--------|
| 任意状态 | sleep（体力 < 20） | 最高 |
| 任意状态 | eat（饥饿 < 30 且有食物） | 高 |
| 任意状态 | play（用户触发） | 高 |
| idle | walk（随机，30s CD） | 中 |
| walk | idle（到达目标位置） | 中 |
| sleep | idle（体力 > 80） | 中 |
| eat | idle（动画完成） | 中 |

## 数值系统

### 属性定义

| 属性 | 范围 | 衰减速度 | 影响 |
|------|------|---------|------|
| hunger（饥饿度） | 0-100 | -1 / 30s | < 30 触发求食；0 心情快速下降 |
| mood（心情） | 0-100 | -0.5 / 30s | 影响表情和行为活跃度 |
| energy（体力） | 0-100 | -0.3 / 30s | < 20 强制睡觉；睡觉时快速恢复 |
| coins（金币） | 0-∞ | 不衰减 | 互动获得，预留商城用途 |

### 互动影响表

| 交互 | hunger | mood | energy | coins |
|------|--------|------|--------|-------|
| 喂食 | +30 | +5 | 0 | -5 |
| 玩耍 | 0 | +15 | -10 | +2 |
| 摸摸 | 0 | +5 | 0 | +1 |
| 自然衰减 | -1/30s | -0.5/30s | -0.3/30s | 0 |
| 睡觉恢复 | -0.5/30s | +1/30s | +2/30s | 0 |

## 数据持久化

### 存储位置

```
~/.shark-pet/data.json
```

### 数据结构

```json
{
  "stats": {
    "hunger": 80,
    "mood": 90,
    "energy": 75,
    "coins": 120
  },
  "position": { "x": 1200, "y": 600 },
  "timestamp": "2026-05-21T10:30:00Z"
}
```

### 保存策略

- 每 30 秒自动保存
- 退出时保存
- 数值变更超过 5% 时保存

## 开发顺序

1. 项目初始化：package.json、Electron 最小可运行窗口
2. Canvas 鲨鱼渲染器：分部件绘制 + 基础浮动动画
3. 行为状态机：idle → walk → sleep 循环
4. 数值系统：属性衰减 + 更新逻辑
5. 用户交互：点击/拖拽/右键菜单
6. 数据持久化：保存/加载
7. 系统托盘 & 打包配置
